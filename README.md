# Spectrogram

Repository for custom spectrogram or custom functions and blocks for GNU Radio.





\---Log \& Info---



21 Aug 2026: The 'vector\_integrator.py' is the first code added here. My first spectrogram is largely being built through GNU Radio, copying a lot of structure from DSPIRA's own spectrogram as learning material. Timed vector integration is a key step for hydrogen line detection, and I am building my own function to do so that can be integrated with GNU Radio python blocks.
